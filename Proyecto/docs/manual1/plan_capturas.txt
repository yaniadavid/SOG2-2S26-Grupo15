REGLAS DE TODAS LAS CAPTURAS
- Se toman solo desde el Odoo desplegado y con los datos ya cargados. Nunca mockups ni capturas simuladas.
- Antes de la sesion: arrancar Cloud SQL y la VM (ops/arrancar_para_calificacion.txt) y correr bloque 01 y TOTALES de sql/demo_final.sql: todas las cifras "esperado" deben dar ok = true.
- Nombre de archivo: cap_NN.png (NN con dos digitos, el numero de este plan). Es el nombre que busca el generador del manual. El tema se anota solo en este plan, no en el nombre.
- Formato PNG, ancho minimo 1280 px, zoom del navegador 100 por ciento, interfaz en espanol.
- Ocultar con recuadro opaco (no difuminado): IP publica o privada, correos personales, contrasenas, tokens, nombres de secretos con valor, numero de proyecto. Recortar la barra de direcciones si muestra la IP. Revisar tambien el historial de la terminal y el prompt.
- Empresa: Guatemala, moneda GTQ, plan contable gt, IVA 12 por ciento incluido. Las cifras visibles deben ser las reales; ninguna se corrige a mano.
- Certificado: el acceso HTTPS usa un certificado publico de Let's Encrypt emitido para la IP; no hay advertencia del navegador y no se documenta ninguna.
- Consultas SQL: se ejecutan con el paquete verificado sql/demostracion (ejecutar_consultas.sh, 01 a 06, demo_final.sql) usando el rol de solo lectura sog2_lectura.
- Convenciones: [OBJ-E] = cifra del enunciado; [PORC-1] = porcion del Integrante 1 (prefijo I1-).
- Responsable: I1 = Integrante 1; I2 / I3 = a cargo de los Integrantes 2 y 3 (ver cada captura).
- Ensayo antes de la toma: no dejar documentos de prueba. Si se uso datos/ensayo_extremo_a_extremo.py, correr --limpiar y verificar los conteos antes de capturar listas.
